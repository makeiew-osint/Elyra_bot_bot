# Elyra_bot_bot

Telegram-бот с единым меню для чата, кода, агента, OCR, генерации и редактирования изображений.

## Запуск

1. Установите Python 3.11+.
2. Создайте окружение и установите зависимости:

   ```powershell
   py -3.11 -m venv .venv
   .\.venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   ```

3. Скопируйте `.env.example` в `.env` и укажите:
   - `TELEGRAM_BOT_TOKEN` — токен от BotFather;
   - `HF_TOKEN` — токен Hugging Face с разрешением на inference.
   - `DATABASE_URL` — PostgreSQL (в production рекомендуется Railway); без него
     используется SQLite для локальной разработки.
4. Запустите:

   ```powershell
   python bot.py
   ```

## Railway

Создайте сервис из этого репозитория и добавьте в **Variables**:

- `TELEGRAM_BOT_TOKEN`;
- `HF_TOKEN`;
- `GEMINI_API_KEY`;
- `BOT_NAME` (необязательно);
- `DATABASE_URL` — PostgreSQL для постоянной истории и чатов;
- `ADMIN_USER_IDS=1881090493`;
- `DAILY_MESSAGE_LIMIT=100`;
- `MAX_FILE_SIZE_MB=20`;
- `HEALTHCHECK_INTERVAL_MINUTES=15`.

Конфигурация запуска находится в `railway.toml`; Railway запускает worker-команду
`python bot.py`. Не загружайте `.env` в репозиторий.

## Модели

Настройки моделей находятся в `config.py`:

- текст, кодинг, агент и анализ изображений: `deepseek-ai/DeepSeek-V4.1-Flash`;
- сложные рассуждения и агент: `zai-org/GLM-5.3-Flash`;
- основной умный чат, код и текстовый анализ файлов: DeepSeek через Hugging Face;
- поиск в интернете: Gemini через `GEMINI_API_KEY` с резервом DeepSeek;
- фото и PDF используют специализированный мультимодальный путь с резервом DeepSeek;
- OCR: `zai-org/GLM-OCR`;
- генерация: `krea/Krea-2-Turbo`;
- реалистичные изображения: `black-forest-labs/FLUX.1-dev`;
- быстрые простые изображения: `Tongyi-MAI/Z-Image-Turbo`;
- редактирование: `black-forest-labs/FLUX.2-dev`.

Некоторые модели Hugging Face могут требовать принятия лицензии или отдельного
провайдера inference. В таком случае бот покажет понятную ошибку в чате, а не
сделает вид, что запрос выполнен.

Маршрутизатор выбирает backend автоматически: основной текстовый ответ,
код и анализ текстовых документов отправляются в DeepSeek, агентские задачи —
в GLM-5.3-Flash, а Gemini используется для поиска и отдельных
мультимодальных форматов. При ошибке Gemini основной ответ всё равно
формируется DeepSeek.

Для генерации изображений бот выбирает модель по описанию: реалистичные и
фотореалистичные запросы направляются в FLUX.1-dev, быстрые простые запросы —
в Z-Image-Turbo, остальные — в Krea-2-Turbo. При ошибке одной модели бот
переходит к следующей доступной.

## Команды

- `/start` — главное меню;
- `/help` — помощь;
- `/about` — описание бота;
- `/cancel` — отменить текущий режим.
- `/clearhistory` — удалить историю текущего пользователя.

Голосовые сообщения временно отключены: бот сообщает пользователю о
недоступности функции и предлагает отправить запрос текстом.

Кнопка «🌐 Поиск в интернете» использует Gemini grounding и доступна только с
ключом Gemini. В режиме OCR принимаются PDF, DOCX, TXT и XLSX: PDF анализирует
Gemini, остальные форматы сначала извлекаются локальными библиотеками.
Фото таблиц и документов по-прежнему обрабатываются через vision/OCR.

История хранится в PostgreSQL (с параметризованными запросами и пулом соединений)
и разделена на именованные чаты. Без `DATABASE_URL` локально используется SQLite.
Команды `/newchat`, `/chats`, `/renamechat`, `/deletechat`, `/switchchat` и
`/export txt|json` управляют чатами и экспортом. Дневной лимит сообщений считается
по UTC и задаётся `DAILY_MESSAGE_LIMIT`; размер файлов ограничен
`MAX_FILE_SIZE_MB`. PDF анализируется Gemini только при наличии ключа, а большие
TXT/DOCX/XLSX обрабатываются частями.

Администраторы из `ADMIN_USER_IDS` (по умолчанию `1881090493`) используют
`/stats`, `/health`, `/maintenance on|off` и `/broadcast текст`. При старте,
ошибках API или внешних провайдеров бот отправляет уведомление администраторам
с cooldown `HEALTHCHECK_INTERVAL_MINUTES`. Голосовые сообщения остаются
отключёнными.

Не публикуйте токены в исходниках или репозитории. Перед публичным запуском
перевыпустите токен, если он уже был опубликован.
